📰 Fake News Classification using AI/ML

----
📌 Overview
This project is a Natural Language Processing (NLP) based Fake News Detection system that classifies news articles as Real (1) or Fake (0) using deep learning (LSTM).

----
⚙️ Tech Stack
Python
TensorFlow / Keras
NLTK
Gensim
Scikit-learn
Pandas, NumPy, Matplotlib

----
🧠 Workflow
Data preprocessing (cleaning, stopwords removal)
Tokenization & padding
LSTM model training
Prediction & evaluation using accuracy and confusion matrix

----
📊 Results
Achieved high accuracy (~99%) on test data

----

📌 Output
1 → Real News
0 → Fake News
